# Controllo Doppio Stepper ESP32

Progetto per il controllo coordinato di due motori stepper con ESP32, display OLED e interfaccia pulsanti.

## Caratteristiche
- Controllo 2 stepper con AccelStepper
- Display SH1107 128x128
- Homing automatico con finecorsa
- Controllo velocità via potenziometri
- Ciclo coordinato con logica custom
- Interfaccia pulsanti (Start/Stop/Pause)

## Hardware
- ESP32 Dev Module
- Stepper driver (DRV8825/A4988)
- Display OLED SH1107
- Finecorsa meccanici
- Relè per controllo torcia
